# MVP 요구사항 정의서 — 보탬

> ⚠️ 이 문서는 [가설 검증](03-가설검증계획.md)과 [정책 결정](05-정책결정서.md)이 끝나기 전에는 확정하지 않는다.
> 컨시어지 MVP(수동 운영)로 H1~H3 검증을 통과한 뒤 작성 착수.

## MVP의 목적

- 검증 대상: (컨시어지에서 검증 못 한) 자동화된 루프에서의 H2, H5
- 성공 기준: ⬜ TBD (예: 4주 내 자연 발생 펀딩 N건, 달성률 M%)

## 범위 원칙

- 참여자 쪽 마찰 제거가 최우선 — 개설자 편의 기능은 후순위
- 미달성 플로우는 MVP에 반드시 포함 (예외 케이스가 아니라 주요 케이스)

## 기능 목록 (초안 — 확정 아님)

### Must (이것 없으면 루프가 안 돎)

- [ ] 펀딩 개설: 상품 링크 등록, 사연 작성, 기한 설정
- [ ] 공유 링크 + 카톡 OG 미리보기
- [ ] 비회원 참여: 금액 선택, 메시지, 결제
- [ ] 진행률 표시 및 실시간 갱신
- [ ] 달성/만료 처리 및 알림 (카카오 알림톡 or 문자)
- [ ] 수령 절차 (D-2 결정 반영)
- [ ] 미달성 처리 (D-1 결정 반영)

### Should (경험 완성도)

- [ ] 참여자 메시지 모아보기 (롤링페이퍼)
- [ ] 감사 인사 발송
- [ ] 완료 화면 → "나도 만들기" 전환 유도

### Won't (MVP 제외 — 기록만)

- 앱 (웹으로 시작)
- 친구 목록/팔로우, 기념일 캘린더, 위시리스트 복수 관리
- 제휴몰 카탈로그 (링크 등록으로 시작, D-2에 따라 변경 가능)

## 비기능 요구사항

- [ ] 결제: PG 선정 (규제 구조 D-3 결과에 종속)
- [ ] 참여 완료까지 3탭 이내 / 모바일 웹 최적화
- [ ] 개인정보: 비회원 참여자의 최소 수집 원칙

## 지표 설계

| 지표 | 정의 | 목표 |
|---|---|---|
| 개설 전환율 | 방문 → 펀딩 개설 | ⬜ |
| 참여 전환율 | 링크 클릭 → 결제 완료 | ⬜ (컨시어지 기준치 대비) |
| 달성률 | 개설 → 목표 달성 | ⬜ |
| 루프 전환율 | 참여자 → 이후 개설 | ⬜ (H5) |
