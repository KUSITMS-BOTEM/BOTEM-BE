# PL 문서 동기화 규칙

## 배경·목적

보탬 기획 문서는 claude.ai 프로젝트 「보탬」에서 Claude 세션과 함께 작성·수정된다. 팀원 누구나 최신본을 볼 수 있도록, 프로젝트 문서가 바뀔 때마다 이 레포의 `PL/docs/`에 같은 내용을 푸시한다.

## 원본과 사본

- **원본**: claude.ai 프로젝트 「보탬」의 문서
- **사본**: 이 레포 `PL/docs/`
- 경로는 그대로 대응한다. 프로젝트의 `<경로>` → 레포의 `PL/docs/<경로>`
  - 예: `00-종합기획서.md` → `PL/docs/00-종합기획서.md`
  - 예: `claude/22-상품권공급사-PG검증.md` → `PL/docs/claude/22-상품권공급사-PG검증.md`
  - 예외: 프로젝트 `README.md` → `PL/docs/README.md` (PL 문서 목차)
- 이 파일(`PL-문서동기화-규칙.md`)은 레포 전용이라 프로젝트에는 없어도 된다.

## Claude 세션 작업 순서

프로젝트 문서를 새로 만들거나 고친 세션은, 작업을 마칠 때 아래를 이어서 한다.

1. `KUSITMS-BOTEM/BOTEM-PLAN` 레포를 push 권한으로 세션에 연결하고 클론한다.
2. 이번 세션에서 바뀐 프로젝트 문서를 위 경로 대응대로 `PL/docs/`에 덮어쓴다. 내용은 프로젝트 문서와 글자 그대로 같게 둔다.
3. `main`을 최신으로 받은 뒤(`git pull --rebase`), 바뀐 파일만 커밋한다.
   - 커밋 메시지: `[DOCS] PL <문서번호·이름> <추가|수정>` (예: `[DOCS] PL 22-상품권공급사-PG검증 추가`)
   - 커밋 작성자는 지율로 둔다: `git config user.name "정지율"`, `git config user.email "jiyul335399@gmail.com"`. 커밋 메시지에 Claude 표기(Co-Authored-By, Claude-Session 등)는 넣지 않는다.
4. `main`에 바로 푸시한다.
5. 레포에서 누군가 `PL/docs/` 파일을 직접 고친 흔적이 있으면(프로젝트 원본과 다르고, 이번 세션이 바꾼 게 아니면) 덮어쓰지 말고 사용자에게 먼저 알린다.

## 미결 사항

- 레포에서 직접 고친 내용을 프로젝트로 역반영하는 절차는 아직 없다. 당분간은 프로젝트를 원본으로 두고, 레포 직접 수정은 피한다.

- 2026-10-20 커밋 작성자를 지율로, Claude 표기 제외
