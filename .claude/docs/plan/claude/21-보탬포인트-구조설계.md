# 21. 보탬 포인트 구조 설계 — 심화 리서치 (2026-10-14)

> [19-결제구조-선불규제](19-결제구조-선불규제.md) 4장(포인트)과 [20-결제UX-설계](20-결제UX-설계.md)의 후속.
> ⚠️ 공개 자료 기반 정리이며 법률·세무 자문이 아님. "확인 필요"로 표시한 항목은 자문 전에 결론 내지 말 것.

## 0. 결론 먼저

1. **포인트로 얻고 싶은 효과는 대부분 '보탬이 잔액을 직접 보관하지 않고도' 얻을 수 있다.**
2. 규제 무게를 가르는 핵심 질문은 **"누구의 돈이, 누구의 지갑에 남아, 어디서 쓰이고, 현금으로 나갈 수 있나"** 네 가지다.
3. 가장 위험한 조합은 **받는 사람이 남들이 낸 돈을 '보탬 잔액'으로 들고 있다가 현금 환급받는 구조**다. 사실상 송금 대행이 되고, 19번 문서의 원칙("돈은 사람에게 가지 않고 상품으로만 나간다")과 정면으로 충돌한다.
4. 그래서 추천 설계는 이렇다.
   - **무상 리워드 포인트(P1)**
   - **참여자 본인 환불 포인트(P2)**
   - **받는 사람 잔액은 등록 발행사의 금액권으로 자동 변환(P3)**
   - '보탬 머니'(충전형 자체 선불)는 등록 또는 법률 자문 이후로 미룸

## 1. 포인트로 풀고 싶은 문제 vs 실제로 필요한 것

| 풀고 싶은 문제 | 포인트가 꼭 필요한가 | 대안 |
|---|---|---|
| 브랜드 화폐 느낌("3만 보탬") | ❌ 표기만으로 충분 | 단위 언어 (P0) |
| 재방문 이유 (저빈도 문제) | 🟡 잔액이 있으면 좋음 | 무상 리워드 (P1) |
| 미달성 시 깔끔한 처리 | 🟡 | 참여자 환불 포인트 (P2) 또는 금액권 (P3) |
| 초과 달성·자투리 금액 처리 | 🟡 | 금액권 자동 변환 (P3) |
| 진행률 신뢰 (P2 문제) | ❌ | 2단계 PG 결제만으로 해결 |
| 결제 수수료 절감 | ❌ 오히려 충전 PG가 고위험 업종 | — |

## 2. 규제 사실 정리

### 2-1. 선불전자지급수단이 되는 조건

- 정의: 이전 가능한 금전적 가치를 전자적으로 저장해 발행하고, **발행인 외의 제3자**로부터 재화·용역을 사는 데 쓰는 수단 (전자금융거래법 정의, 벤처스퀘어 2025-07 변호사 기고)
- **2024-09-15 개정으로 넓어짐** (율촌 / 법률신문, 에이핀)
  - 업종 기준(2개 업종 이상) 삭제 → 제3자 사용 여부가 핵심
  - 단일 가맹점 면제가 '10개 이하' → '1개(동일 사업주)'로 축소. 동일 브랜드 복수 점포는 1개로 봄
  - 계열사 사용 면제 삭제
  - 금액 면제는 **발행잔액 30억 원 미만 그리고 연간 총발행액 500억 원 미만** (둘 다 충족해야 함)
  - 무상 발행분은 지급보증이나 상환보증보험에 가입하면 면제 가능. 보증 범위는 제3자 사용 비율에 따라 달라짐
  - 유상·무상이 섞인 지갑은 다른 면제 요건도 충족해야 하는 경우가 많음
- **실질 관리 주체 원칙**: E쿠폰을 단순 재판매하는 사업자의 경우, 명칭과 상관없이 선불충전금을 실질적으로 관리하는 주체(발행사)가 등록 의무를 짐 (금융위 해석, 율촌 뉴스레터 2024 가을)
  → **보탬이 기프티쇼 금액권을 유통만 하면, 등록 의무는 원칙적으로 발행사 쪽에 있다.** 다만 보탬의 실제 구조로 자문 확인 필요.

### 2-2. 등록하면 지게 되는 의무

| 항목 | 내용 | 출처 |
|---|---|---|
| 자본금 | 20억 원 이상 | 벤처스퀘어 2025-07 |
| 선불충전금 보호 | **100% 별도관리** (은행·신탁·보험), 안전자산 운용, 양도·담보 금지 | 율촌 / 법률신문 |
| 환급 | 가맹점 축소나 불리한 조건 변경 시 잔액 전액 환급, 약관에 명시 | 율촌 / 법률신문 |
| 보유 한도 | 기명식 200만 원 / 무기명식 50만 원 | 시행령 13조·감독규정 별표3 (nepla 2024-08 기준) |
| 실명확인 | 50만 원 초과 시 고객확인 의무 → 비대면 실명확인 2가지 이상 | 알체라 |
| 공시 | 분기 종료 후 10일 안에 충전금 규모·신탁·보험 내역 공시 (2020 가이드라인 기준) | 디지털데일리 |
| 미등록 영업 | 3년 이하 징역 또는 2천만 원 이하 벌금 | 디지털데일리 |
| 등록 소요 | 약 6개월 → 잔액 약 20억 원 시점에 준비 시작 권장 | 에이핀 |

**확인 필요**
- 등록 면제 사업자에게도 별도관리 의무가 적용되는지 (공개 자료에서 명확히 확인 못 함)
- 특금법(자금세탁방지) 의무 범위

**참고 사례**: 네이버·토스는 법적 의무가 없는 무상 리워드 포인트도 자발적으로 보험에 가입함 (MTN 2022-03)

### 2-3. 환급 규칙 (실무 기준선)

카카오 전자금융거래 이용약관 제25·26조 사례:

| 항목 | 내용 |
|---|---|
| 7일 이내 | 구매(충전) 취소하면 전액 환급 |
| 일반 환급 | 유상 잔액에서 수수료를 빼고 환급. **무상분은 환급 대상 아님** |
| 수수료 면제 | 60% 이상 사용 시 (1만 원 이하는 80%), 가맹점 축소, 결함 등 |
| 유효기간 | 유상은 1년 이상 (정하지 않으면 5년), 소멸시효 5년. 무상은 이벤트별로 정함 |
| 유효기간 지난 뒤 | 90% 환급 |

공정위 표준약관 시정 (2025-09-16, 10개 상품권 사업자)
- 유효기간 지난 뒤 환급: 5만 원 이하 90%, 5만 원 초과 95%, **포인트로 받으면 100%**
- 탈퇴했거나 비회원으로 샀어도 잔액 환불 가능
- 7일 이내 요청은 수수료 없이 전액 환급

→ **유상 잔액을 가진 사람은 사실상 언제든 현금으로 돌려받을 권리가 있다.** 이게 구조 설계의 핵심 제약이다.

### 2-4. 세무

| 항목 | 처리 | 출처 |
|---|---|---|
| 충전금 | 받을 때는 선수금(부채). 사용할 때 매출 | 마일스톤 |
| 자사 적립금 | 사용 시 할인으로 보아 과세표준에서 차감 | 마일스톤 |
| 유상·무상이 섞여 구분 불가 | 과세 쪽으로 볼 위험 → **원장을 버킷별로 분리** | 마일스톤 |
| 상품권 직접 매입 후 재판매 | '상품권 매매업'은 면세로 해석되는 사례 (판매액 전체가 매출, 세금계산서 없음, 매입세액 불공제) | taxly Q&A, 서면부가2017-1727 |
| 상품권 판매 대행 | 과세 (수수료가 매출) | 같은 출처 |

→ 2단계 기프티콘 판매가 '매매'인지 '대행'인지에 따라 업종과 부가세가 달라진다. 현재 등록 업종(전자상거래 소매업, 일반과세)과 맞는지 **세무사 확인 필요**.

### 2-5. 그 외

- **PG 심사**: '포인트·캐시 충전'은 고위험 업종이고, 예시에 '펀딩 플랫폼 포인트'가 들어 있음. 환불정책, 보증보험 요구 가능성 (포트원)
- **머지포인트 (2021)**: 약 20% 할인 판매 + 가맹점 약 2만 곳 + 미등록 영업으로 3년 운영 → 판매 중단, 사용처 축소, 환불 대란 (바이라인네트워크)
  - 교훈 1: 할인 판매로 키우지 않는다
  - 교훈 2: 등록 여부를 커지기 전에 판단한다
- **네이버페이 (2022)**: '충전 포인트'를 '네이버페이 머니'로 이름을 바꿔 무상 '포인트'와 분리 → **유상과 무상은 이름부터 나누는 게 업계 표준**

## 3. 핵심 프레임: 4개 질문

| 질문 | 안전한 답 | 위험한 답 |
|---|---|---|
| ① 누구 돈인가 | 보탬 마케팅비 (무상) | 사용자가 낸 돈 (유상) |
| ② 누구 지갑에 남나 | 낸 사람 본인 | **남의 돈이 받는 사람 지갑에** |
| ③ 어디서 쓰나 | 보탬이 직접 파는 것만 | 제3자 가맹점·브랜드 |
| ④ 현금으로 나가나 | 낸 사람에게 취소·환급만 | 받는 사람에게 현금 환급 |

②와 ④가 동시에 '위험'이면 → 참여자 돈이 받는 사람에게 현금으로 가는 구조 = **송금·정산 대행**. 피한다.

## 4. 보탬 포인트 옵션

| 코드 | 이름 | 구조 | ①②③④ | 규제 무게 | 효과 | 판정 |
|---|---|---|---|---|---|---|
| **P0** | 보탬 단위 | 금액 표기를 "○만 보탬"으로만 | 해당 없음 | 없음 | 브랜드 | ✅ 지금 |
| **P1** | 리워드 보탬 (무상) | 참여·초대·감사카드 보상으로 지급. 펀딩에 보태거나 보탬 상품 구매에만 사용. 출금·환급 불가. 유효기간 1년 | 무상 / 본인 / 보탬 / 불가 | 낮음 (단일 가맹점 or 무상 보증 면제 검토) | 재방문, 전환 | ✅ 2단계와 함께 |
| **P2** | 환불 보탬 (참여자 본인) | 2단계 미달성 시 참여자가 "카드 취소" vs "보탬으로 받기(+보너스)" 선택 | 유상 / **본인** / 보탬 / 본인에게만 환급 | 중간 (본인 돈이라 환급해도 송금 아님. 7일·60% 환급 규칙은 적용) | 미달성 처리, 재참여 | 🟡 자문 후 |
| **P3** | 잔액 → 금액권 자동 변환 | 받는 사람의 자투리, 초과분, 미달성분을 **등록 발행사 금액권**(네이버페이 포인트 쿠폰, 올리브영 기프트카드, 편의점·다이소 금액권 등, 기프티쇼 비즈 판매 상품)으로 발송 | 유상 / 받는 사람 / **발행사** / 발행사 책임 | 낮음~중간 (보탬은 유통) | 미달성·초과 해결 | ✅ 2단계 핵심 |
| **P4** | 받는 사람 보탬 잔액 | 모인 돈을 받는 사람의 '보탬 잔액'으로 보관하고 나중에 보탬 상품 구매 | 유상 / **남** / 보탬 / **환급 요구 시 현금** | 높음 (송금화, 단일 가맹점 해석 다툼) | 재방문 최대 | ❌ 보류 |
| **P5** | 충전형 보탬 머니 | 참여자가 미리 충전해서 펀딩에 사용 | 유상 / 본인→남 / 보탬 / 환급 | 높음 + PG 고위험 | 낮음 (참여는 1회성이라 충전 동기 약함) | ❌ |
| **P6** | 등록 선불업자 제휴 | 등록 사업자의 포인트·머니를 보탬 안에서 사용·지급 (화이트라벨 등) | 발행사 책임 | 계약 의존 | P4 효과를 합법적으로 | 🔵 규모가 커진 뒤 검토 |

### 왜 P3이 핵심인가

- 미달성, 초과, 자투리 금액이 모두 "금액권 한 장"으로 끝난다. **받는 사람 지갑에 보탬 잔액이 남지 않는다.**
- 네이버페이 포인트 쿠폰은 사용처가 넓어 사실상 현금 대체 경험을 준다. 기프티쇼 비즈 새 학기 발송 데이터(디지털데일리 2025-02 보도)에서 초중고 대상 발송량 1위였다.
- 환급·별도관리·보험 의무는 발행사(등록업자)가 진다.
- 확인할 것
  - 기프티쇼 비즈의 재판매 허용 여부 (19번 문서 TODO)
  - 금액권 최소·최대 권종과 단가 (자투리 1,700원 같은 금액을 어떻게 처리할지)
  - 금액권을 '선물'로 받는 사람에게 발송하는 게 송금으로 해석될 여지 (자문 질문 11번)

### P1 설계 디테일 (무상 리워드)

- 이름부터 분리: **"리워드 보탬"** (유상분이 생기면 그쪽은 "보탬 머니"). 네이버페이처럼 처음부터 나눔
- 지급처
  - 첫 참여 500 보탬
  - 친구 초대 후 그 친구가 개설하면 1,000 보탬
  - 감사카드 발송 300 보탬
  - (금액은 예시, 마케팅 예산에서 역산)
- 사용처: ① 친구 펀딩에 보태기 ② 보탬이 직접 파는 기프티콘 구매
  - ①은 **보탬이 마케팅비로 대신 보태 주는 것**이라, 받는 사람에게는 2단계 결제와 똑같이 상품으로만 나간다
- 금지: 현금 출금, 회원 간 직접 양도, 할인 판매(머지 교훈)
- 유효기간 1년, 만료 30일 전 알림
- 발행 예산 상한을 월별로 고정 → 무상 발행잔액이 계속 쌓이지 않게

### P2 설계 디테일 (참여자 환불 포인트, 2단계 미달성)

- 미달성 마감 화면 선택지
  - ⓐ 카드 결제 취소 (부분취소, 3~5영업일)
  - ⓑ 1만 보탬으로 받기 + 5% 보너스
- ⓑ는 **본인이 낸 돈이 본인 지갑에 남는 구조**라, 나중에 환급해 줘도 낸 사람 본인에게 돌아갈 뿐 송금이 아님
- 보너스분은 무상(P1 버킷)으로 따로 적립 → 세무상 구분
- 7일 이내 전액 환급, 60% 사용 후 잔액 환급 등은 표준약관 수준으로 보장
- 유상 잔액이 생기는 순간 → 발행잔액 집계 대상. **단일 가맹점 면제 해당 여부를 자문으로 확인한 뒤 출시**

## 9. 규모 감각 (면제 구간까지 거리)

- 발행잔액 30억 원 = 2만 명이 평균 15만 원씩 동시에 들고 있는 수준
- 연간 500억 원 = 15만 원짜리 펀딩 약 33만 건
- → 금액 기준 면제는 꽤 오래 유지될 규모. 그래도 **면제 ≠ 의무 없음**(환급 약관, 공정위 기준, PG 심사)이고, 단일 가맹점 해석이 틀리면 금액 기준 하나만 남는다.
