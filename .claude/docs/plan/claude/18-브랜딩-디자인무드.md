## 2. 진행률 모티프 (케이크 조각 대체)

케이크 조각은 쓰지 않기로 함. 기준: "한 명이 하나씩 보탠다"를 단위로 쪼갤 수 있어 진행률, 대기/확정, 첫·마지막 뱃지, 공유카드, 미달성 화면을 같은 언어로 그릴 수 있을 것.

| 모티프 | 보탬 1회 = | 대기/확정 | 미달성 | 판단 |
|---|---|---|---|---|
| **스티커판** | 참여자가 고른 스티커 1장 | 대기는 점선 반투명, 확정 시 탁 붙음 | 꾸며진 판이 그대로 남음 | **기본 추천** — 테마 확장성, 금액 비공개와 궁합, 내트꾸 결 |
| **레이드** | 보스(위시)에 공격 1회 | 대기는 데미지 숫자만 흐리게 | "여기까지 깎았다" | 어그로·공유카드·발표용 보조. 위시를 '적'으로 만드는 점 주의 |
| 영수증 | 영수증 한 줄 | 대기 줄은 흐린 잉크 | 소계 영수증 | 완료 화면 같은 '순간'용 |
| 엔딩 크레딧 | 크레딧 한 줄 | 대기는 회색 이름 | Special Thanks 롤 | 롤링페이퍼 공개 후 마지막 장면용 |
| 블록 쌓기 | 블록 1개 (금액 클수록 큼) | 대기 블록 점선 | 쌓은 높이 기록 | ⚠️ 블록 크기 = 금액 → D-5 금액 비공개와 충돌 |

## 5. 브랜딩 아이디어 (8개 후보)

1. 동네 선물가게 (차분·신뢰) — 주문서/우표/포장 완료 → D안
2. 레이드 파티 (어그로) — "혼자는 못 깬다. 파티 모집 중", 첫타·막타 → E안
3. 다이어리 꾸미기 (감성·바이럴) — "내 위시, 같이 꾸며줘" → F안
4. **보탬 = 동사 (채택 방향)**
5. 염치 없는 위시 (B급) — "염치는 없지만 위시는 있다", H1 체면 부담에 정면 대응
6. 영화 크레딧 — "이 선물의 제작진", 생일 = 개봉일
7. 계모임 2.0 — "총무 없는 계모임"
8. 조각 경제 (스타트업 톤) — "30만 원짜리 선물, 커피 한 잔씩이면 끝"

공통 장치 후보: 오리지널 마스코트 '보탬이', 서비스 전용 용어, 확정 시 "짤랑" 시그니처 사운드, 생일 0시 롤링페이퍼 공개 리추얼.

추천 조합(제안): 4번을 기본 언어로 + 화면 톤은 3번(다꾸) + 공유카드·발표는 2번이나 5번으로 어그로.

## 6. 채택 방향: 보탬 = 동사

**채택 이유 (지율)**: 나중에 금액권이 아니라 포인트로 바꿔 PG를 붙일 수 있을 것 같아서. 브랜드 단위가 처음부터 '보탬'이면 돈이 오가는 방식이 바뀌어도 사용자 언어가 유지됨. (단계별 결제 구조와 규제는 [19번 문서](19-결제구조-선불규제.md))

선례: 토스머니, 배민페이머니처럼 브랜드명이 화폐 단위가 되는 방식.

### 용어 사전 (초안, 팀 확정 전)
| 용어 | 뜻 | 예시 |
|---|---|---|
| 보태다 / 보태기 | 참여하다, 메인 버튼 동사 | "나도 보태기" |
| 보탬 | 참여 1회이자 금액 단위 | "3만 보탬" |
| 보탬 요청 | 위시를 공유하는 행동 | "보탬 요청 보내기" |
| 보탬 링크 | 공유되는 펀딩 페이지 링크 | "보탬 링크 줘" |
| 보탬러 | 참여자 | "보탬러 7명" |
| 위시주 | 펀딩 개설자 (후보) | "위시주가 확인하면 반영돼요" |
| 첫보 / 막보 | 첫·마지막 보탬 뱃지 | "막보 자리 비어 있음" |
| 보탬 완료 | 목표 달성 | "보탬 완료! 이제 지유가 살 차례" |

### 단위 표기 규칙 (제안)
- 일상·공유·밈 카피: **"3만 보탬"** (만 단위 축약 + 보탬)
- 송금·결제·정산 화면: **"30,000원"** (정확한 원 단위, 장난 없이)
- 진행 상황: "98,000원 남았어요", 참여 수는 "보탬 7개"

### UI 카피 세트
나도 보태기 / 보탬 요청 만들기 / 보탬 링크 복사 / 보냈어요 / 보탬 확인 중 · 지유가 확인하면 반영돼요 / 하린이 3만 보탬 했어요 / 98,000원 남았어요 · 커피 세 잔이면 끝 / 막보 자리 비어 있음 / 보탬 완료! 이제 지유가 살 차례 / 여기까지 같이 보탰어요 / 돈 말고 한마디만 보태도 돼요 / 세 번째로 보탬
