# 커피챗 스크립트 (최종 간단 버전) — 보탬 (2026-10-03)

저희는 갖고 싶은 선물을 친구들이 조금씩 보태서 완성해주는, 사람 중심의 크라우드펀딩 서비스 '보탬'입니다.

받는 사람은 "이거 사줘"라고 말하기 어렵고, 주는 사람은 뭘 줄지 모르고, 여럿이 같이 사려면 총무 한 명이 계좌, 입금 확인, 정산까지 다 떠안아요. 선물하기 시장은 10조 원까지 커졌는데, 여럿이 모아 한 명에게 주는 자리는 아직 비어 있어요.

보탬은 받는 사람이 위시를 올리면 링크가 생기고, 친구들이 앱 설치 없이 원하는 만큼 조각을 채워서 선물을 완성해요. 금액 대신 역할로 표시돼서 적게 낸 사람도 부담이 없고, "사줘"라고 말하는 부담은 친구가 몰래 열어주는 서프라이즈 모드로 덜어내요.

모아줘와 달리 받는 사람이 '받았어요'를 눌러야 진행률이 확정돼서 믿을 수 있고, 현금 전달이 아니라 '선물 도착'까지 이어지는 경험을 만들어요. 처음엔 송금 링크로 가볍게 시작하고, 지금은 설문·인터뷰·실제 생일 운영으로 검증하고 있어요.

총무도 정산도 없이, 받고 싶던 선물이 친구들 손으로 완성되는 순간을 만드는 게 보탬입니다.
