# 설문조사 설계 — 보탬 (n=100)

> 작성 2026-09-24 · 목적: 실태 정량화 + 인터뷰/컨시어지 리쿠르팅 + 컨셉 반응, 세 가지를 한 설문에.
> 원칙: **미래 의향("쓰실 건가요?")이 아니라 과거 행동("최근에 어떻게 했나요?")으로 묻는다.** 설문은 태도는 잘 재도 행동 변화(H2)와 체면(H1)은 과대·과소평가하기 쉬우므로, 최대한 실제 경험에 앵커링한다.
> 연계: [03-가설검증](03-가설검증계획.md) H1·H2 / [04-인터뷰](04-인터뷰.md)(정성 심층은 여기가 담당) / [08-경쟁분석](08-경쟁분석.md) / [11-기획허점리뷰](11-기획허점리뷰.md) P2·P3.

## 0. 이 설문으로 알 수 있는 것 / 없는 것 (먼저 읽기)

설문 100명은 **얼마나 흔한가(prevalence)** 와 **세그먼트별 차이**를 재는 데 강하다. 반대로 **"실제로 지갑을 열까(H2)"** 와 **"공개적으로 위시를 등록할까(H1)"** 같은 행동·문화 리스크는 설문 숫자만으로 판정하면 안 된다. 그건 컨시어지 MVP와 인터뷰가 판정하고, 설문은 그 근거를 정량으로 보강하는 역할이다.

| 설문이 답할 수 있는 것 | 설문이 답 못 하는 것 (→ 인터뷰/컨시어지로) |
|---|---|
| 공동선물 pain(총무·정산·원치 않는 선물)이 얼마나 흔한가 | "링크 주면 진짜 5천원 보낼까"의 실제 전환율 (H2) |
| 어떤 세그먼트(총무 경험자 등)가 pain이 큰가 | 위시 공개 시 실제로 등록까지 가는가 (H1의 행동 단계) |
| 카톡 위시리스트/모아줘 등 대안의 사용·이탈 실태 | "왜"의 깊은 맥락과 감정 |
| 인터뷰·컨시어지에 넣을 후보 발굴 | |

**판정 규칙**: 설문의 의향성 문항(C섹션)은 "판정 근거"가 아니라 "인터뷰 질문 후보·세그먼트 힌트"로만 쓴다. H1/H2 최종 판정은 03 문서 기준(요청 5명 중 3명 등록, 링크 수신자 50% 참여)을 따른다.

## 1. 표본·채널 계획

목표 n=100. 4개 채널을 쓰되 **채널이 곧 편향**이므로 소프트 쿼터를 두고, 응답마다 유입 채널을 기록해 교차분석으로 편향을 드러낸다.

| 채널 | 목표 배분 | 편향 특성 | 방어 |
|---|---|---|---|
| 대학 커뮤니티·에타 | ~40 | 20대 대학생 쏠림, 동아리 총무 다수(얼리어답터와 겹침 ← 좋음) | 연령대 문항으로 분포 확인 |
| 인스타·카톡 지인 | ~25 | 지율 관계망 = 응답자가 지율과 닮음(치명적 편향) | 최소화, "지인 여부" 태그로 분리 분석 |
| 오픈채팅·설문 품앗이 | ~20 | 불특정 다수, 무성의 응답 위험 | 어텐션 체크·소요시간 필터 |
| 잇타 네트워크 | ~15 | IT 성향 편향, 프로덕트에 우호적 | 우호 편향 감안해 별도 태깅 |

- **핵심 편향 경고**: 인스타·카톡·잇타는 "지율과 닮은 사람들"이라 우호적으로 나올 수 있다. 분석 때 **`지인/우호 채널` vs `낯선 채널(에타·오픈채팅)`을 반드시 갈라서** 본다. 두 그룹 결과가 크게 다르면 우호 채널 수치는 버린다.
- 소요시간 목표 **5~7분**(약 18~22문항). 품앗이·오픈채팅 이탈을 막으려면 이 이상 늘리지 않는다.
- 보상: 소액 기프티콘 추첨(응답 끝 연락처는 선택). 품앗이 채널엔 필수.

## 2. 문항 구조 한눈에 (분기 로직)

```
S. 스크리너·기본정보 (전원)
  └ S3 최근 6개월 공동선물 참여 경험?
        ├ 있음 → A. 보내는 입장 실태 (심층)
        └ 없음 → A는 건너뛰고 B로
B. 받는 입장 · 위시 공개 (전원) ← H1
C. 대안·현재 도구 (전원) ← 경쟁
D. 컨셉 반응 (전원, 신중 프레이밍) ← 수요(참고용)
R. 리쿠르팅·연락처 (전원, 선택)
```

전원이 B·C·D를 답해 **분모를 100으로** 유지(실태·prevalence 계산 가능), A는 경험자만 답해 **심층 정보**를 얻는다.

## 5. 분석 계획 (돌리기 전에 미리 정한 기준)

응답 받은 뒤 자의적으로 해석하지 않도록, **읽는 방법을 먼저 고정**한다.

**실태(전체 100 기준)**
- 공동선물 경험률 = S3 "예" 비율. (얼마나 보편적 행동인가)
- pain 보편성 = A5에서 "딱히 불편 없었다" 제외 비율. 60% 미만이면 문제 자체가 약하다는 신호.
- **pain 강도(A7) 분포가 이 프로젝트의 리트머스**: 4–5점 비율이 높아야 H2 전환 여지. 3점 이하에 몰리면 "있으면 좋지만 없어도 그만" → P4 경고 현실화.

**H1(위시 공개)**
- B4에서 (A) 비율, B5의 4–5점 비율 → 공개 수용도.
- 단, B2에서 "표현해본 적 없다" + B3 "부담돼서 안 씀"이 다수면 태도(B4·B5)가 긍정이어도 **행동은 안 한다**는 뜻 → 태도>행동 괴리로 읽고 H1은 "미검증, 컨시어지로 확인"으로 남긴다.
- B5-1에서 "친구가 열어주면"이 최다 → 개설 주체 피벗 강하게 검토.

**H2(전환)**
- 설문으로 직접 판정 안 함. A7 pain 강도 + C1-1 이탈 이유로 **가설의 방향성만** 본다.

**세그먼트·편향 교차분석 (필수)**
- 총무 경험자(A1) vs 일반 참여자: pain 강도·컨셉 반응 차이. 총무만 아프면 얼리어답터 좁다는 뜻.
- 지인/우호 채널 vs 낯선 채널: D1·B5 점수 비교. 격차 크면 우호 채널 수치 폐기.
- 연령대별 H1 반응(20대 초반 vs 30대).

**정제 규칙**: 어텐션 체크 오답 + 60초 미만 완주 + 직선응답 → 제외. 제외 후 유효 n을 명시.

## 6. 구글폼 세팅 팁

- 섹션 분리 + S3 응답 기반 **섹션 이동(분기)** 설정. B3·B5의 하위질문도 응답 기반 이동.
- A6는 "이전 문항 응답 파이핑"이 구글폼선 안 되므로, A5 보기를 그대로 단일선택으로 반복 배치(또는 Tally·Typeform 쓰면 파이핑 가능).
- 채널별 **URL을 4개로 나눠** 각 링크에 `entry.xxx=채널명` 프리필 → S2 자동기록(백업으로 S2 문항도 유지).
- 진행률 바 표시 ON, 대부분 문항 필수, 주관식·연락처는 선택.
- 배포 전 **본인+지인 3명 파일럿**으로 오해되는 문항·소요시간 체크 → 5분 넘으면 A섹션에서 A9·A10부터 잘라낸다.

## 7. 설문의 위치 (착각 방지)

이 설문은 03 검증계획의 **보조 수단**이다. 100명이 "좋다"고 해도 그건 H1·H2 통과가 아니다. 로드맵(12)상 9월 3~4주 압축 검증의 핵심은 여전히 **인터뷰 5명 + 컨시어지 1~2건**이고, 설문은 그 위에 "이게 나만의 문제가 아님"을 정량으로 얹고, 인터뷰·컨시어지 대상자를 R섹션으로 실어나르는 깔때기다. 설문 결과는 [03 검증 결과 기록표]와 [02 린캔버스]에 반영한다.
