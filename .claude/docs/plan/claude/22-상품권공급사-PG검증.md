# 22. 모바일상품권 공급사 비교 + 상품권 판매 PG 통과 가능성 검증 (2026-10-18)

> 2단계(A: PG + 기프티콘) 실행 가능성 점검. 관련: [19](19-결제구조-선불규제.md), [20](20-결제UX-설계.md), [21](21-보탬포인트-구조설계.md)
> ⚠️ 공개 자료 기반. 각 사 조건은 바뀔 수 있으니 계약 전 직접 확인.

## 결론

1. **공급사는 여러 곳이 있다.** 다만 보탬이 필요한 건 셀프 가입형 '대량 발송' 계정이 아니라 **재판매(위탁판매) 계약**이다. PG 심사에서 위탁판매계약서와 발행사 서류를 요구하는 곳이 있다.
2. **상품권·기프티콘 판매는 PG '위험업종'이지만, 심사를 거치면 가능한 PG가 다수 있다** (토스페이먼츠, KG이니시스, KSNET, 다날 등). NHN KCP, 스마트로, KPN, 카카오페이는 입점 불가로 표기돼 있다.
3. **더 큰 리스크는 '펀딩' 구조다.** 포트원 위험업종 안내에서 펀딩은 **입점 불가** 업종이다. 사유는 결제 시점과 실행 시점이 다르고, 목표 미달성 시 일괄 취소가 생길 수 있어서다.
   → 2단계는 **'미달성 시 일괄 환불' 없는 구조**(모인 만큼 금액권 지급, 21번 P3)로 가야 PG 통과 가능성이 높다.

## 1. 모바일상품권 B2B 공급사

| 플랫폼 | 운영사 | 특징 | API | 보탬 관점 |
|---|---|---|---|---|
| **기프티쇼 비즈** | KT알파 | 셀프 가입 대량 발송. 1회 최대 1만 건, 등급별 할인. 15만 고객 (2025-03) | 오픈 API | 원래 '기업이 직접 선물하는' 용도. 재판매 허용 여부 확인 필요 |
| **기프티쇼 프로** | KT알파 | 영업 미팅 → 계약(상품·정산 확정) → 계정 → 발송·정산. 상품 신청 폼 관심 분야에 '재판매' 항목 있음 | 쿠폰 발송 API, 고객사별 대시보드 | **재판매 계약 협의 창구로 가장 유력** |
| **센드비** | 윈큐브마케팅 | 누구나 최대 20% 할인, 1회 최대 1천 건 | 오픈 API | 대안 1순위 |
| **비즈콘** | SK플래닛 | 가입 즉시 6% 할인, 1회 최대 1천 건 | 문의 | 대안 |
| **쿠프마케팅** | 쿠프마케팅 (2005 설립) | B2B SaaS, 복지몰 솔루션 + 모바일상품권 발송. 클라이언트 3,450개, 브랜드 2,750개 (2024) | 문의 | 브랜드 수가 많음. 제휴 협의 |
| 카카오톡 선물하기 for Biz | 카카오 | 사업자 대량 선물, 1회 최대 5천 건 (2021 출시) | 공개 API 확인 안 됨 | 재판매·연동은 입점 계약 필요 (05 D-2) → 제외 |

참고: 센드비 비교 글에 따르면 세 플랫폼(센드비, 기프티쇼 비즈, 비즈콘) 모두 세금계산서는 발급되지 않는다 → 상품권 매매업 회계와 연결 (21번 2-4)

### 공급사에 물어볼 것

1. 보탬처럼 **소비자에게 재판매하는 구조**를 허용하는가? 허용한다면 **위탁판매(판매대행) 계약서**를 써 주는가?
2. PG 심사용 **발행사 법인등기부등본, 인지세 관련 서류**를 제공하는가?
3. 금액권 권종 (최소 금액, 자투리 처리), 네이버페이 포인트 쿠폰 등 범용 금액권이 있는가?
4. 매입 단가와 할인율, 정산 방식 (선충전 vs 후정산)
5. 발송 실패 시 재발송, 유효기간 연장, 환불 처리는 누가 하는가?

## 2. 상품권 판매 PG 통과 가능성

### 2-1. 포트원 위험업종 안내 기준

**상품권·기프티콘 (위험업종, 환금성)**

| PG | 조건 |
|---|---|
| 토스페이먼츠, 나이스정보통신, 웰컴페이먼츠, KG파이낸셜, 토스페이, KICC | 심사 후 가능 |
| KG이니시스 | 인증 강화 필수, 카드사 기준 금액 제한 가능. 기프티콘은 **인지세 서류나 위탁판매계약서** 필요할 수 있음 |
| KSNET | 모바일쿠폰 판매 가능. **위탁판매계약서 + 발행사 법인등기부등본** 필수 |
| 다날 | 담보, 승인 한도 또는 정산 한도 설정 필수 |
| 헥토파이낸셜 | 상품권은 내통장결제 불가 |
| 키움페이 | 가상계좌·계좌이체 제한 |
| 갤럭시아머니트리 | 일정산 불가, 할부 6개월 |
| 네이버페이 | 상품권은 신용카드 결제 제한 |
| **입점 불가** | NHN KCP, 스마트로, KPN, 카카오페이 |

**포인트 충전 (위험업종)**: 심사 후 가능한 PG가 많지만, 충전 1천~10만 원, 취소는 원결제수단으로만 등의 조건이 붙음. 충전 후 현금 출금 구조는 입점 어려움 → 21번 P5(충전형) 비추천 근거 추가

**펀딩 (입점 불가 업종)**: 목표 미달성 시 일괄 취소 가능성, 결제 요청 시점과 실행 시점이 다른 구조(크라우드 펀딩)

### 2-2. 보탬 2단계에 적용하면

| 설계 요소 | PG 관점 리스크 | 대응 |
|---|---|---|
| 상품권 판매 | 위험업종 (심사 후 가능) | 위탁판매계약서와 발행사 서류 확보 → 토스페이먼츠 1순위로 신청 |
| 미달성 시 일괄 부분취소 | **펀딩 = 입점 불가** 사유에 해당 | **일괄 환불 없음**: 모든 결제는 반드시 상품으로 이행 (목표 상품 or 모인 만큼 금액권, 21번 P3) |
| 결제 후 마감일까지 대기 | 결제와 이행 사이의 시차 | 마감 기한 상한 설정 (예: 최대 14일), 기한 표시 |
| '펀딩' 용어 | 심사 담당자가 펀딩 업종으로 분류 | 실제 구조를 정직하게 설명하되 "단체 선물(함께 선물하기) 모바일상품권 판매"로 정의. **용어만 바꾸는 게 아니라 구조 자체가 일괄취소 없는 판매여야 함** |
| 개별 취소 | 전자상거래법 청약철회 | 발송 전 개별 취소는 허용 (7일, 원결제수단) → 일괄이 아닌 개별 단위 |

### 2-3. 유사 PG 리스크 (주의)

법률사무소 칼럼(2026-05)은 상품권·쿠폰 판매처럼 보여도 **다른 가맹점의 결제대금을 모아 수수료를 떼고 정산하면 미등록 PG업**으로 처벌된 판례(수수료 약 1%, 약 2.95%)를 소개한다.

→ 보탬은 **판매대금을 개설자나 다른 판매자에게 정산하지 않고, 공급사에서 상품을 사서 발송만** 해야 한다. 19번 원칙("돈은 사람에게 가지 않고 상품으로만")이 PG 관점에서도 필수.

### 2-4. 심사 통과 체크리스트 (모비인사이드 2026-03 + 포트원)

- [ ] 사이트에 사업자번호, 통신판매업 번호, 대표자, 고객센터 표시
- [ ] 상품 상세 (브랜드, 권종, 유효기간, 사용처)
- [ ] 환불정책 구체화 (개별 취소 기간, 발송 후 환불은 발행사 정책 등)
- [ ] 위탁판매계약서, 발행사 법인등기부등본 (공급사에게 받기)
- [ ] 기한 상한, 금액 상한 (예: 펀딩당·1인당)
- [ ] 거절되면 2차 PG(포트원 등 경유) 또는 보완 후 1~3개월 뒤 재신청

## 3. 다음 액션

1. KT알파 **기프티쇼 프로** 상담 신청 → 재판매·위탁판매 계약 가능 여부 문의
2. 동시에 센드비(윈큐브), 쿠프마케팅에 같은 질문
3. 계약 조건 확보 후 토스페이먼츠에 **업종 사전 문의** (상품권 판매 + 단체 선물 구조 설명)
4. 05 D-1(미달성 처리) 결정: **"일괄 환불 없음, 모인 만큼 금액권"**을 2단계 기본안으로 확정 검토
