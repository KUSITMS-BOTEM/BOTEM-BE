# 보탬(Botem) 종합 기획서

> 지금까지의 모든 논의를 하나로 압축한 문서. 이 문서 하나만 읽으면 프로젝트의 현재 상태를 전부 알 수 있다.
> 최종 갱신: 2026-09-09 · 상세는 각 항목의 링크 문서 참조

---

## 1. 제품 한 줄 정의

**보탬은 퍼스널 크라우드 펀딩이다** — 갖고 싶은 걸 등록하면, 친구들이 원하는 만큼 보태서 하나의 선물을 완성한다.

기존 크라우드 펀딩이 프로젝트를 후원한다면, 보탬은 **사람(Person)이 펀딩의 중심**이다.

## 2. 해결하는 문제

공동 선물은 지금 이렇게 진행된다 — 단톡방 개설 → 총무 지정 → 계좌이체 → 금액 확인 → 정산 → 구매. 번거롭고, 받는 사람이 원하는 걸 정확히 주기도 어렵다. 그리고 30만 원짜리를 혼자 사긴 부담스럽지만 1만 원은 누구나 낼 수 있는데, 이걸 쉽게 모을 방법이 없다.

## 3. 시장에서 배운 것 (가장 중요한 발견)

| 서비스 | 모델 무게 | 결과 |
|---|---|---|
| 프레제뉴 (2021~2024) | 무거움 — 결제 수납 + 실물 구매·배송 대행 | 💀 서비스 종료 |
| 모아줘 (운영 중) | 가벼움 — 계좌 직송금, 플랫폼은 진행률만 표시 | ✅ 생존 (최대 경쟁자) |
| 내 트리를 꾸며줘 (2021) | 초경량 — 돈 없음, 링크 + 메시지만 | 🚀 3일 만에 180만 명 |

**결론: 돈을 깊게 만질수록 죽었고, 가벼울수록 퍼졌다.** 이 한 줄이 보탬의 모든 설계 결정을 지배한다.

- 프레제뉴 실패 추정 원인 3가지: ① 친구 관계가 아닌 **팬덤에서만** 루프가 돌았다 ② 생일은 연 1회라 **재방문 이유가 없다** ③ 배송·CS·규제를 다 진 **무거운 모델**이었다. (공개 부검 자료 없음 — 대표 커피챗이 유일한 확인 수단)
- 카카오톡 선물하기: 위시리스트는 있으나 **N:1 공동 펀딩은 아직 없음** — 자리는 비어 있다. 다만 "카카오가 버튼 하나 붙이면?"에 대한 방어 논리는 아직 공백.
- 해외에선 이미 검증된 모델 (Throne, Leetchi, GiftCrowd, Kudoboard).

## 4. 제품 구조 — 3층 (현재 확정된 큰 그림)

생일 펀딩만으로는 바이럴 주기가 너무 길다(참여자의 다음 생일까지 평균 6개월). 그래서 3층으로 쌓는다.

```
1층  선물 취향 테스트      → 획득: 생일과 무관하게 연중 바이럴 (MBTI형 포맷)
2층  위시 프로필 (상시)    → 활성화: 저빈도 해결, 생일 D-30에 자동 펀딩 전환
3층  펀딩 + 상품          → 수익화: 송금 링크 → 기프티콘 확장
```

- **1층이 획득, 2층이 활성화, 3층이 수익화.** 기존에는 3층부터 설계하고 있었다.
- **서프라이즈 모드**: 본인이 "사줘"를 뿌리는 게 아니라, 친구가 위시 프로필을 보고 **몰래 모금방을 여는** 역방향. 롤링페이퍼·마니또 문화와 정합하며 H1(체면 부담)을 원천 제거.
- 볼륨 확장은 **위로(1·2층 완성도)**, 아래로(PG 수납·실물 배송) 확장은 금지 — 프레제뉴의 무게.

→ 상세: [09-바이럴제품전략](09-바이럴제품전략.md)

## 5. 펀딩 페이지 재미 요소

페이지를 모금함이 아니라 **놀이판**으로: ① 케이크 조각 채우기(진행률의 놀이화) ② 금액 대신 역할 뱃지("첫 조각", "초 꽂음" — 금액 서열화 방지) ③ **개설자 공약**("완성되면 노래방 영상 찍어 보냄" — 받기만 하는 구조 탈출) ④ 메시지 생일 당일 일괄 오픈 ⑤ 빈 조각 밈톤 카피(페이지가 대신 조름) ⑥ **참여자용 자랑 카드**(참여자도 공유거리를 얻어야 확산이 N배).

→ 상세: [13-펀딩페이지-재미요소](13-펀딩페이지-재미요소.md)

## 6. 비즈니스 모델 (확정)

**원칙: 유저는 돈을 내지 않는다. 수익은 커머스에서 받는다.**

| 단계 | 구조 | 수익원 |
|---|---|---|
| **B (MVP)** | 참여자 → 개설자 계좌로 직접 송금. 플랫폼 무수납 = 규제 회피 | 쿠팡 파트너스 어필리에이트 ~3% (30만 원 상품 ≈ 9천 원/펀딩) |
| **A (확장)** | 참여자가 PG로 '선물 조각' 결제 → 달성 시 기프티쇼 비즈 API로 기프티콘 발송 | 상품권 마진 + **gross-up** |
| **A′ 실물 대리구매** | — | ❌ **기각** (프레제뉴를 죽인 무게) |

- **gross-up 확정**: 목표가에 수수료 포함(30만 원 → 30.9만 원), **참여자 부담**, **"수수료 포함" 투명 고지 필수**. 10명이 나누면 1인당 900원이라 저항이 거의 없고, 숨기면 신뢰가 무너진다.
- ⚠️ **단, gross-up은 A 단계에서만 작동한다** — B에서는 돈이 우리를 거치지 않아 걷을 방법이 없다. MVP 수익은 어필리에이트뿐.

→ 상세: [05-정책결정서](05-정책결정서.md) D-2/D-4

## 7. 제휴 전략 — "협업 요청"이 필요 없는 것부터

| Tier | 대상 | 조건 |
|---|---|---|
| 1 (오늘 가능) | 쿠팡 파트너스, 토스 아이디 송금 링크 | 계약 불필요, 누구나 가입 |
| 2 (사업자등록만) | **기프티쇼 비즈(KT알파) 기프티콘 발송 API**, PG | 사업자등록증 + 승인 1~2일, 플랫폼 이용료 없음 |

## 8. 바이럴 마케팅 4원칙

1. **무대는 인스타 스토리 하나로 고정** — 공유 단위는 링크가 아니라 '올리고 싶은 카드'. 개설자용 + **참여자용** 양면.
2. **점화는 팬덤, 지속은 친구** — 생일 임박 마이크로 인플루언서(1~5만) 5~10명으로 점화. 프레제뉴 부검의 역이용.
3. **시즌 캘린더** — 11월 말 런칭 직후가 크리스마스·연말 = 선물 최대 시즌. 12월 '내 크리스마스 위시' 캠페인으로 동시 데드라인 효과를 빌린다. **런칭 타이밍이 우연히 최적.**
4. **채널은 2개만** — 인스타그램 + 에브리타임/캠퍼스 커뮤니티.
