1. **동일 컨셉의 국내 서비스가 이미 존재했고, 하나는 죽었고 하나는 살아있다.**
   - 프레제뉴(2021~): 우리와 거의 동일한 컨셉 → **서비스 종료됨**

2. **카카오 선물하기는 위시리스트는 있지만 N:1 공동 펀딩은 없다** — 아직 비어 있는 자리.
3. **해외에는 이 모델이 이미 검증돼 있다** (Throne, Leetchi, GiftCrowd 등) — 컨셉 자체는 성립하나, 한국식 실행이 관건.

## 국내 직접 경쟁

### 프레제뉴 (presenu.com) — 💀 서비스 종료 (2차 부검: 2026-07-15)

- **컨셉**: "모아서 선물하는 펀딩 플랫폼"(Present+You). 원하는 선물 등록 → 친구들이 함께 결제 → 달성 시 배송. **보탬 기획안과 거의 동일.**
- **이력**: 2021년 김주연 대표 창업 → 2022~2024년 초까지 펀딩 개설 흔적(펀딩 ID 타임스탬프 기준) → 이후 종료. 언론에 보도된 폐업 사유·투자 이력 없음 (공개 post-mortem 부재).
- **간접 증거로 본 실패 원인 추정** (⚠️ 추정임 — 확정 아님):
  1. **트래픽이 팬덤에 쏠림**: 최대 성공 사례가 이정 작가 팬 펀딩(300명+ 참여). 정작 핵심 타깃인 친구 사이 펀딩은 개별 사례가 산발적 → 친구 관계에서는 루프가 안 돌았을 가능성 (H1/H2 실패 신호). Throne이 크리에이터 시장에만 머문 것과 동일한 패턴.
  2. **저빈도 구조**: 1인당 생일은 연 1회. 개설자 재방문 이유가 없어 리텐션이 구조적으로 어려움.
  3. **무거운 모델**: 결제 수납 + 상품 구매·배송 대행 = PG 수수료·규제·CS 부담을 다 지는 구조. 수익 없이 비용만 큰 모델이었을 가능성.
- **직접 컨택 TODO**: 김주연 대표 (성대신문 인터뷰 이력, 성균관대 출신 추정). 커피챗 요청 가치 매우 큼 — 추정 1~3을 확인해줄 유일한 소스.

### 모아줘 (moajwo.me) — ✅ 운영 중

- **컨셉**: 생일 선물 펀딩. 링크 하나로 친구들 참여, 실시간 달성률.
- **핵심 구조**: 선물+**개설자 계좌번호** 등록 → 참여자가 **개설자 계좌로 직접 송금** → 플랫폼은 진행률 표시만.
- **시사점 (중요)**:
  - 자금을 플랫폼이 보관하지 않아 **전자금융업 규제를 완전히 우회** → 우리 H4 가설의 실존 사례.
  - 수수료 0원 = 수익 모델이 사실상 없음. "예쁜 계좌이체 래퍼"에 가까움.
  - 결제 대신 계좌이체라 '상품 구매 보장'이 없음 → 받은 돈을 딴 데 써도 됨 = **선물 경험이 아니라 돈 경험**. 보탬이 차별화할 수 있는 지점.
  - 인스타 스토리 자동 이미지 생성 등 공유 UX에 집중 — 배울 점.

### 카카오톡 선물하기 — 잠재 최대 위협

- **위시리스트**: 존재. 공개 설정 시 친구가 열람 가능. "친구에게 물어보기"(위시 등록 요청) 기능도 있음 → **H1(위시 공개 체면 부담)에 대한 카카오의 답이 이미 여기 있음. 사용률 리서치 가치 큼.**
- **같이쓰기**: 교환권 공유 기능이지 공동 펀딩이 아님.
- **N:1 공동 결제**: 현재 미지원으로 파악됨 (⬜ 앱에서 직접 재확인 필요).
- **방어 논리 숙제**: 카카오가 위시리스트에 '함께 선물하기' 버튼 하나 붙이면 끝나는 것 아닌가? — 이 질문에 대한 답이 포지셔닝의 핵심.

- **Botem (주식회사 보템?)**: 대전 소재 인체감지 센서 기업(1997~, 재실 센서·스마트미터). Crunchbase/PitchBook 등재. 업종이 달라 상표 충돌 가능성은 낮으나 KIPRIS 확인 필수.
- **botim**: UAE 대형 메신저 앱 — 철자 유사(botim/botem). 글로벌 확장 시 혼동 소지.
- **판단**: '보탬' 단독으로는 검색 점유가 어려움(정부 시스템 + 일반명사). 후보 대응: ① 복합 네이밍(예: '보탬박스', '기프트보탬' 류) ② '보템'(Botem) 재고 ③ 그대로 가되 브랜드 검색어를 'Botem'으로 통일. → 상표 검색 후 결정.
