# 제휴/파트너십 전략 — 보탬

> 질문: "쇼핑몰·결제 시스템을 다 연결해야 하는데, 다른 기업·플랫폼에 협업을 요청할 수 없을까?"
> 답: 할 수 있다. 단, **'협업 요청'이 필요 없는 것부터 쓰는 순서**가 중요하다. 트래픽 없는 초기 스타트업에게 대기업 정식 제휴 문은 열리지 않는다 — 그리고 다행히 초기엔 열릴 필요도 없다.

## 3단계 제휴 사다리

### Tier 1 — 허가·계약 불필요, 오늘 바로 가능 (라이트 MVP 단계)

| 대상 | 무엇 | 조건 | 보탬 활용 |
|---|---|---|---|
| 쿠팡 파트너스 | 어필리에이트 링크, 구매액 ~3% 수수료 | 누구나 가입. API는 누적 판매 15만 원 후 활성화 | 개설자가 등록한 상품 링크를 파트너스 링크로 변환 → **수수료 0원 유지하면서 첫 수익원** |
| 링크프라이스 등 제휴 네트워크 | 11번가·G마켓·SSG 등 어필리에이트 | 가입 승인 | 쿠팡 외 쇼핑몰 커버 |
| 토스 아이디(익명) 송금 링크 | 계좌번호 노출 없이 링크로 수금 | 개설자가 개인적으로 발급 | 라이트 모델의 송금 수단. 개설자 계좌번호 공개 부담 제거 |
| 카카오페이 송금 (오픈채팅 경유 등) | 링크 기반 송금 | 공식 '송금 링크 API'는 미공개 ([개발자 포럼 문의 스레드](https://developers.kakaopay.com/forum/t/topic/286) 존재) | 딥링크 연결은 가능하나 약관 검토 필요 ⚠️ |

**⚠️ 확인 필요**: 쿠팡 파트너스 약관상 '타인이 등록한 상품 링크의 자동 변환'이 허용되는지 — 대가성 고지 의무 포함.

### Tier 2 — 사업자등록증만 있으면 계약 가능 (정식 MVP 단계)

| 대상 | 무엇 | 조건 | 보탬 활용 |
|---|---|---|---|
| **기프티쇼 비즈 (KT알파)** | 모바일상품권 B2B 발송 + **자동 발송 API** | 사업자등록증, 가입 승인 1~2영업일, 플랫폼 이용료 없음(상품 단가에 마진 포함) | **가장 중요한 제휴.** 달성/미달성 시 "모인 만큼 기프티콘 지급" 구현 → [D-1·D-2](05-정책결정서.md)를 계약 하나로 해결. GiftCrowd 모델의 한국판 |
| 쿠프마케팅·즐거운(주) 등 | 기프티쇼 비즈 대안 상품권 API | 유사 | 단가 비교 협상용 |
| 포트원(구 아임포트)·토스페이먼츠 | PG 결제·에스크로 | 사업자 + 심사 | 자금 수납 모델로 전환하는 날 필요. 라이트 모델에선 불필요 |

### Tier 3 — 트래픽 확보 후에만 열리는 정식 BD (검증 이후)

- **버티컬 커머스** (29CM·무신사·오늘의집 등): 타깃(2030)이 겹침. 제안 구조 = "우리 위시리스트/펀딩 트래픽을 너희 상품 페이지로 보내준다" — **우리가 보낼 트래픽이 생긴 뒤에만 성립.**
- **카카오·토스**: 제휴 상대이자 잠재 경쟁자·인수자. 검증 전 제휴 요청은 아이디어만 노출하는 하방 리스크가 더 큼. 접촉은 지표가 생긴 후.
- BD의 지렛대는 언제나 **전환 데이터** (펀딩→구매 전환율, 펀딩당 참여자 수). MVP 검증 전 대기업 제휴 미팅은 시간 낭비로 간주한다.

## 결론: 초기 스택 제안

```
상품 등록  →  쿠팡 파트너스 링크 변환 (수익, 무계약)
돈 흐름    →  토스 아이디 송금 링크 / 카카오페이 딥링크 (무수납, 무규제)
달성 지급  →  기프티쇼 비즈 API (유일한 초기 계약, 사업자등록 필요)
```

→ **정식 '협업 요청' 없이도 쇼핑몰 연동 + 지급 구조가 완성된다.** 사업자등록이 첫 실무 액션.
