## 진행 원칙

1. **가벼울수록 산다** — 돈을 깊게 만지는 방향으로는 확장하지 않는다.
2. **코드보다 검증 먼저** — 핵심 가설은 수동 운영으로 먼저 검증한다.
3. **결정은 개발 전에** — 정책 결정과 검증은 개발 시작 전에 끝낸다.
4. **유저는 돈을 내지 않는다** — 수수료는 커머스 측에서 받는다.
5. **언어는 '보탬' 하나로** — 결제 수단이 바뀌어도 "○만 보탬"은 유지한다.
