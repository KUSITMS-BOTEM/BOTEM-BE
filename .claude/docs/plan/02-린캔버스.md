# Lean Canvas — 보탬 (Botem)

> 초안. 인터뷰([04](04-인터뷰.md))와 가설 검증([03](03-가설검증계획.md)) 결과에 따라 갱신한다.
> 마지막 갱신: 2026-07-15

## 1. 문제 (Problem)

1. 공동 선물은 총무·계좌이체·정산 등 수작업으로 번거롭다.
2. 받는 사람이 원하는 선물을 정확히 전달하기 어렵다.
3. 고가 선물에 소액으로 부담 없이 참여할 방법이 없다.

**기존 대안**: 카톡 단체방 + 계좌이체 + 총무, 카카오 선물하기(1:1), 현금/상품권

## 2. 고객군 (Customer Segments)

- **받는 사람(펀딩 개설자)**: 20~30대, 생일·졸업·취업·집들이를 앞둔 사용자
- **보태는 사람(참여자)**: 개설자의 친구·동료·가족
- **얼리어답터 가설**: 대학 동아리·친구 모임의 총무 경험자 (현재 pain이 가장 큰 사람)

## 3. 고유 가치 제안 (UVP)

**"총무 없이, 정산 없이, 원하는 선물을 정확하게."**

- 하이레벨 컨셉: 개인을 위한 와디즈 / 위시리스트 + 더치페이의 결합

## 4. 솔루션 (Solution)

1. 원하는 상품 등록 + 링크 하나로 공유
2. 자유 금액 참여 (5천 원부터)
3. 진행률·참여 현황 자동 관리, 달성 시 상품 구매 연결

## 5. 채널 (Channels)

- 카카오톡 공유 링크 (핵심 — 참여자가 앱 설치 없이 참여 가능해야 함)
- 인스타그램 스토리 공유
- ⬜ TBD: 초기 유저 확보 채널 (대학 커뮤니티? 인플루언서?)

## 6. 수익 흐름 (Revenue Streams)

- ⬜ 후보 1: 커머스 제휴 수수료 (참여자 저항 없음, 제휴 필요)
- ⬜ 후보 2: 펀딩 수수료 (구현 쉬움, 참여자 저항 큼)
- ⬜ 후보 3: 프리미엄 기능 (테마, 메시지 카드 등)
- → [정책 결정서 D-4](05-정책결정서.md)에서 결정

## 7. 비용 구조 (Cost Structure)

- PG 결제 수수료 (~2~3%, 소액 다건 구조라 부담 큼 — 수익 모델과 직결)
- 서버/인프라, 개발 인건비
- ⬜ 규제 대응 비용 (전자금융업 등록 시) → [정책 결정서 D-3](05-정책결정서.md)

## 8. 핵심 지표 (Key Metrics)

- **North Star 후보**: 완성(달성)된 펀딩 수 / 월
- 펀딩 개설 수, 펀딩당 평균 참여자 수, 달성률, 참여자→개설자 전환율 (바이럴 루프)
