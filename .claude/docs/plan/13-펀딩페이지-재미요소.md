# 펀딩 페이지 재미 요소 — 보탬

> 문제: "나에게 펀딩해줘"를 어떻게 부담 없이, 재미있게 어필하게 만들 것인가.
> 해법: 페이지를 **모금함이 아니라 친구들이 함께 채우는 놀이판**으로 만든다. H1(체면 부담)을 설득이 아니라 재미로 덮는다.

## 6개 장치 (서로 맞물리는 하나의 구조)

### 1. 케이크 조각 채우기 — 진행률의 놀이화

- 목표 금액을 8조각 케이크로 표현. 참여하면 조각 하나가 참여자 색+이름으로 채워짐.
- 숫자 게이지(모금함)를 시각적 완성 게임으로 치환. "75% 달성"이 아니라 "두 조각 남았어".
- 테마 확장 가능: 크리스마스 트리, 어항, 뽑기머신, 앨범 채우기 → 시즌·취향별 테마가 재방문·꾸미기 욕구로 연결.
- [허점 P2](11-기획허점리뷰.md)(송금 확인 불가) 완화와도 연결: 정확한 금액 게이지가 아니라 '조각'이라 금액 오차 기대치가 낮아짐.

### 2. 금액 대신 역할 뱃지 — 서열화 방지

- 참여자를 금액이 아니라 **참여 순서·행동**으로 표기: "첫 조각", "딸기 올림", "초 꽂음", "마지막 한 조각".
- [D-5(금액 공개 범위)](05-정책결정서.md)를 정책이 아니라 UX로 해결. 적게 낸 사람의 부담 제거 → 참여 전환율 방어.

### 3. 개설자 공약 — 받기만 하는 구조 탈출

- 개설자가 공약을 건다: "완성되면 새 헤드폰 끼고 노래방 영상 찍어서 전원에게 보냄".
- 효과 셋: ① 일방적으로 받는 게 아니게 되어 체면 부담↓ ② 친구들에게 참여 유인 제공 ③ 공약 자체가 웃긴 공유거리.
- **H1 대응의 핵심 장치.** 서프라이즈 모드([09](09-바이럴제품전략.md))와 함께 이중 방어.

### 4. 메시지 당일 일괄 오픈 — 감정적 클라이맥스

- 참여자 메시지는 잠겨 있다가 생일 당일 한 번에 열림(롤링페이퍼 개봉 순간).
- 마감일에 감정 피크를 배치해 "완성되는 순간"을 이벤트화. 개설자의 인증샷 동기도 여기서 발생.

### 5. 빈 조각의 어필 카피 — 페이지가 대신 조른다

- 남은 조각 수에 따라 밈톤 문구 자동 노출: "두 조각 남았어", "내 위시가 굶고 있음", "한 조각만 더".
- 개설자가 직접 "사줘"라고 말하지 않아도 페이지가 대신 말해줌 → 체면 부담을 시스템이 흡수.

### 6. 참여 완료 자랑 카드 — 참여자도 공유거리를 얻는다

- 참여 직후 "지유의 케이크에 3번째 조각을 보탬" 스토리용 이미지 자동 생성.
- 개설자만 공유하면 확산이 1채널, 참여자도 공유하면 펀딩 1건이 N개 피드로 번짐. **바이럴 계수의 핵심.**

## 맞물림 구조

```
조각(진행률 놀이) → 뱃지(금액 비공개) → 공약(참여 유인)
                                          ↓
      자랑 카드(참여자 확산) ← 당일 오픈(클라이맥스)
```

## 구현 메모

- 1·5는 프론트 작업 위주(SVG/애니메이션), 6은 서버 이미지 생성 파이프라인 필요([09 1층](09-바이럴제품전략.md)의 결과 카드 생성기와 동일 인프라 재사용).
- 3(공약)은 텍스트 필드 하나 + 완성 시 리마인더로 시작 가능 — 비용 대비 효과가 가장 큼.
- 우선순위 제안: **3 → 1 → 6 → 2 → 4 → 5**
