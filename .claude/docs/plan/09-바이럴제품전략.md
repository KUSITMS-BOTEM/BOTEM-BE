# 바이럴 제품 전략 — 보탬 (v2, 2026-07-15 3층 구조로 개편)

> 방향: 젊은 세대에서 빠르게 바이럴되는 쉽고 가벼운 프로덕트.
> v2 변경: "생일 펀딩 툴" 단일 제품 → **3층 구조**. 개발팀 규모에 맞는 볼륨은 기능 추가가 아니라 3층 전체를 완성도 있게 짓는 것으로 확보한다.

## 왜 3층인가

생일 펀딩만으로는 바이럴 주기가 너무 길다(참여자의 다음 생일까지 평균 6개월). 내트꾸의 폭발은 전 국민 동시 데드라인(크리스마스) 덕분 — 생일은 흩어져 있어 그 효과가 없다. 그래서:

```
1층  놀이 (선물 취향 테스트)      → 획득: 생일과 무관하게 연중 바이럴
2층  위시 프로필 (상시 존재)      → 활성화: 저빈도 해결, 생일 D-30 자동 전환
3층  펀딩 + 상품 (돈은 마지막)    → 수익화: 송금 링크 → 기프티콘 확장
```

- 사례 근거: 테스트 포맷(MBTI·퍼스널컬러)의 반복 검증된 확산력 + Throne의 위시 프로필 + 기존 라이트 펀딩 결정.
- **H1(체면 부담) 해결 장치 = 서프라이즈 모드**: 본인이 "사줘"를 뿌리는 게 아니라, 친구가 위시 프로필을 보고 **몰래 모금방**을 여는 역방향. 롤링페이퍼·마니또 문화와 정합. 본인 개설(정방향)과 병행 지원.

## 개발 볼륨 (팀 빌드 기준 — 5주에 3층 전부)

### 1층 — 선물 취향 테스트 (획득 엔진)

- 문항 엔진(12문항 내외), 결과 유형 8종, **결과 카드 이미지 서버 생성**(스토리 공유용), 유형별 상품 추천 매핑
- 결과 페이지 → "네 위시 3개 등록해봐" 전환 퍼널
- 공학 포인트: OG/이미지 생성 파이프라인, 전환 트래킹

### 2층 — 위시 프로필 (활성화 엔진)

- 카카오 로그인, 프로필 페이지(링크인바이오형, 테마 꾸미기 = 놀이성)
- 위시 등록: **상품 링크 파싱 크롤러**(이미지·가격 자동 추출, 실패 시 수동 폼 폴백)
- 생일 D-30 자동 펀딩 전환 로직, D-day 리마인더 알림
- **서프라이즈 모드**: 친구가 여는 몰래 모금방 — 초대 링크, 당사자 차단 로직, 생일 당일 공개 스케줄러

### 3층 — 펀딩 (수익화 엔진, 기존 결정 유지)

- 펀딩 페이지(조각 채우기 비주얼), 비회원 참여(금액 조각+메시지), 송금 딥링크, 참여 인증
- 마감 처리(모인 만큼 전달 리프레임), 생일 당일 메시지 일괄 오픈(롤링페이퍼), 달성 인증 이미지 생성
- 어필리에이트 링크 변환(쿠팡 파트너스), 알림(알림톡/문자)
- 운영 장비: 신고·모더레이션, 어드민 대시보드, 핵심 지표 트래킹(K-factor, 층간 전환율)

### 팀 규모별 스코프 조절 노브

| 팀 규모 | 조절 |
|---|---|
| 3명 이하 | 서프라이즈 모드를 초대 링크만으로 축소, 프로필 테마 1종, 어드민 최소 |
| 4~5명 | 위 전체 |
| 6명+ | 프로필 꾸미기 인터랙션(캔버스), 유형별 상품 추천 피드, 참여자용 자랑 카드 자동 생성까지 |

> 원칙 유지: 볼륨 확장은 **1·2층(놀이·프로필)의 완성도**로. 3층에 실물 배송·PG 수납을 붙이는 방향의 확장은 금지(프레제뉴의 무게).

## 바이럴 마케팅 큰 틀 4원칙

1. **무대는 인스타 스토리 하나로 고정.** 공유 단위는 링크가 아니라 '올리고 싶은 카드' — 개설자용("D-7 내 케이크 채워줘") + **참여자용("OO의 선물에 3번째 조각을 보탬")** 양면. 참여자도 자랑거리를 얻어야 펀딩 하나가 여러 피드로 번진다. 기존 '생일 D-day 스토리' 문화에 얹혀 새 행동을 요구하지 않는다.
2. **점화는 팬덤, 지속은 친구.** 프레제뉴 부검의 역이용 — 생일 임박 마이크로 인플루언서(1~5만) 5~10명의 실제 펀딩으로 점화, 친구 관계 루프가 리텐션을 담당.
3. **시즌 캘린더.** 11월 말 런칭 직후가 크리스마스·연말 = 선물 최대 시즌. 12월 '내 크리스마스 위시' 캠페인으로 동시 데드라인 효과를 빌린다. 이후 발렌타인·화이트데이·신학기로 연결.
4. **채널은 2개만**: 인스타그램(스토리) + 에브리타임/캠퍼스 커뮤니티(시드).

## 측정 (층 구조의 성공 기준)

- 1층→2층 전환율 (테스트 완료 → 위시 등록): 바이럴이 자산이 되는가
- 2층→3층 활성화율 (프로필 보유자의 생일 펀딩 개설): 제품의 심장
- 3층 K-factor (참여자 → 테스트/프로필 생성): 루프 완성
- 펀딩당 평균 스토리 공유 수
