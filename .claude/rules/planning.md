# Planning Documents

- 별도 GitHub 저장소 `BOTEM-PLAN`을 기획 문서의 기준으로 사용합니다.
- 연동 전에는 사용자가 제공한 요구사항과 현재 코드를 기준으로 작업합니다.
- 추후 기획 문서가 이 저장소에 동기화되면 `.claude/docs/plan/`에서 관련 문서를 먼저 확인합니다.
- 기획 문서에 없는 정책을 임의로 추가하지 않습니다.
- 기획 문서와 현재 구현이 충돌하면 임의로 선택하지 않고 사용자에게 알립니다.
- 동기화된 기획 문서는 백엔드 저장소에서 직접 수정하지 않습니다.
- 현재는 `BOTEM-PLAN` 자동 동기화나 GitHub 트리거를 구성하지 않습니다.
